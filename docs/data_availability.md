# Data and code availability

Text for the manuscript's availability statements, with the exact
identifiers a reviewer or reader needs.

---

## Code availability

All analysis code is openly available at

    https://github.com/Senekw/A-random-signature-null-for-ICI-transcriptomic-biomarkers

under the MIT licence. The repository contains the complete pipeline
(cohort download, harmonization, signature-library assembly, cohort gate,
scoring, random-signature null calibration, single-axis and confound
analyses, meta-analysis, leave-one-cohort-out ceiling, headline-number
collection, and figure generation), the pre-specified analysis
configuration, the pre-specification document with its deviations section,
and a unit-test suite that verifies the null model is calibrated under the
null hypothesis. `make all` reproduces the analysis from an empty clone.

## Data availability

No patient-level data is redistributed. All cohorts are public.

The analysis uses the **PredictioR / ORCESTRA** immune-checkpoint-blockade
compendium: uniformly-processed ICI-treated transcriptomic cohorts, each
distributed as a `MultiAssayExperiment` object with an individual Zenodo
DOI. The exact manifest used — cohort name, DOI and download URL for every
cohort as retrieved — is committed at `config/orcestra_manifest.json`, and
`R/00_download_cohorts.R` records a per-file md5 checksum at download time
to `results/cohort_download_provenance.csv`.

Cohort inclusion follows the pre-specified gate in
`docs/methods_prespec.md` §2; every cohort's criterion values, pass or
fail, are written to `results/cohort_gate.csv`, and exclusions are
reported with their failing criterion.

## Signature availability

Signature gene membership is assembled from maintained upstream sources at
build time rather than transcribed:

* canonical named ICI predictors — curated CSVs in
  [`bhklab/SignatureSets`](https://github.com/bhklab/SignatureSets), the
  signature companion of the PredictioR compendium;
* immune / immuno-oncology gene sets — `signature_collection` from
  [IOBR](https://github.com/IOBR/IOBR), restricted to the roster in
  `config/signature_roster_iobr.txt`;
* infiltration and purity reference — the ESTIMATE 141-gene immune and
  stromal signatures (Yoshihara et al., Nat Commun 2013), committed as
  reference data at `config/estimate_gene_sets.csv` with source and
  symbol-update provenance in the file header.

`signatures/signature_provenance.csv`, regenerated by
`scripts/01_build_signatures.py`, lists every signature with its upstream
path, primary-publication PMID, direction and gene-set size.
`scripts/verify_roster.py` re-derives the roster from the current upstream
release and reports any drift.

## Reproducibility

Every number quoted in the manuscript is regenerated into
`results/headline_numbers.json` by `scripts/08_headline_numbers.py`, each
entry tagged with the result table and column that produced it. Figures
are drawn only from committed result CSVs, so a figure cannot disagree
with a table. The random seed (20260705) is fixed in
`config/analysis_config.yaml`, and seed stability is checked as part of
the pipeline.
